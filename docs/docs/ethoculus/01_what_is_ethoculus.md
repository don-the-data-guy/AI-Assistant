# What Is Ethoculus?

Ethoculus is a simple, downloadable generative AI starter platform.

The first version has one job: make local AI easy to install and easy to use.

Ethoculus is designed for people who want a practical starting point, not a 200-page engineering maze. Clone the project. Start Docker. Pull a model. Open a browser. Chat.

## The plain-English idea

Ethoculus is a local AI workbench.

It runs on your machine. It gives you a browser-based chat interface. It lets you test open models. It can later grow into a document-aware, ethically constrained AI assistant using RAG.

The name combines ethics and vision: the eye that checks the machine.

## What Ethoculus includes

1. Docker Compose setup.
2. Ollama model runner.
3. Open WebUI browser interface.
4. Starter model download script.
5. Basic document/RAG path.
6. Documentation written for ordinary users, technical learners, and civic-minded builders.

## What Ethoculus does not include

1. It does not store large AI model files in GitHub.
2. It does not promise perfect answers.
3. It does not replace a lawyer, doctor, accountant, teacher, or engineer.
4. It does not remove the duty to verify.
5. It does not pretend that “open” automatically means “ethical.”

## Why local-first matters

Local-first AI gives people a chance to learn and experiment without immediately sending every prompt to a cloud provider. That does not make it magically safe, but it changes the default relationship between the user and the system.

Instead of asking, “What can the platform collect?” Ethoculus starts with a better question:

What should the user control?

## Why RAG comes before fine-tuning

RAG stands for Retrieval-Augmented Generation. Instead of retraining the model every time new information appears, RAG lets the system retrieve relevant information from documents and feed that context into the conversation.

That matters because most useful work is not about a model knowing everything. It is about a model being grounded in the right source at the right time.

## The Ethoculus rule

Do not trust the machine because it sounds confident.

Trust improves only when claims are checked against sources, context, and consequences.

## Who Ethoculus is for

1. Students learning AI.
2. Lawyers and policy people studying AI risk.
3. Developers who want a fast local stack.
4. Writers who want a private drafting assistant.
5. Families and small organizations that want to understand generative AI without being locked into a vendor.
6. Ethical AI builders who want to start simple and improve in public.

## The first promise

Ethoculus Version 1 is intentionally modest:

Download it. Start it. Run a model. Ask a question. Upload a document. See what happens.

That is enough for the first rung of the ladder.
